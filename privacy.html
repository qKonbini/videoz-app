VIDEOZ privacy policy

Last updated: 17 November 2026

VIDEOZ is a private tool run by its owner, the creator Kao (qKonbini), on the owner's own computer. It has one user: its owner. It is not offered to the public.

Google and YouTube data VIDEOZ accesses

With the owner's consent through Google sign-in, VIDEOZ uses the YouTube Data API and YouTube Analytics API to:

  • upload the owner's own videos to the owner's own YouTube channel;
  • read the upload and processing status of those videos;
  • read statistics for the owner's own channel and videos (for example views, likes, comments and average view duration).

How the data is used

The data is used only to publish the owner's videos and to measure how they perform, so the owner can improve them. It is not used for advertising.

Storage and sharing

The data and the sign-in token are stored only on the owner's own computer. The token is stored encrypted. VIDEOZ does not sell, share or transfer Google user data to anyone.

Other people's data

VIDEOZ does not collect personal data from viewers or from any other person. It has no accounts, sign-up or tracking on this website.

Removing access

The owner can remove VIDEOZ's access at any time at myaccount.google.com/permissions, and can delete the stored token and data from the computer.

VIDEOZ uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
